# Dasara Wish to Tanii

An elegant, interactive two-page Dussehra greeting featuring a procedural 3D golden Apta leaf with custom inscription and a heartfelt Marathi Vijayadashami wish.

## Requirements

- Node.js 22.12 or later (or Node.js 20.19 or later)
- npm

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (by default, <http://localhost:5173>).

## Other commands

```sh
npm test
npm run lint
npm run build
npm run preview
```

The home page is `/`; the wish reveal is directly available at `/wish`.
